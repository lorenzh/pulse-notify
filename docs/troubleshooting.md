# Troubleshooting

Messages are quoted from the code. `<x>` marks a value that varies.

## Startup

| Message                                                                                                                                                                                                        | Cause                                                                                                                                                      | Action                                                                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pulse-notify: PULSE_NOTIFY_CONFIG is required`                                                                                                                                                                | The variable is unset or empty.                                                                                                                            | Set it to the path of the channel config file.                                                                                                                                                                       |
| `pulse-notify: cannot read config file <path>: <reason>`                                                                                                                                                       | The file is missing or not readable. In Docker, the file is not mounted.                                                                                   | Fix the path or the mount.                                                                                                                                                                                           |
| `pulse-notify: config file <path> is not valid JSON: <reason>`                                                                                                                                                 | The file has a JSON syntax error.                                                                                                                          | Fix the JSON.                                                                                                                                                                                                        |
| `pulse-notify: config must be an object`                                                                                                                                                                       | The top level is not an object.                                                                                                                            | Use `{ "channels": [...] }`.                                                                                                                                                                                         |
| `pulse-notify: config.channels must be a non-empty array`                                                                                                                                                      | `channels` is missing, not an array or empty.                                                                                                              | Add at least one channel.                                                                                                                                                                                            |
| `pulse-notify: channels[<n>] must be an object`                                                                                                                                                                | An entry is not an object.                                                                                                                                 | Fix entry `<n>` (counting from 0).                                                                                                                                                                                   |
| `pulse-notify: channels[<n>].id must be a non-empty string`                                                                                                                                                    | An id is missing or empty.                                                                                                                                 | Give every channel an `id`.                                                                                                                                                                                          |
| `pulse-notify: duplicate channel id "<id>"`                                                                                                                                                                    | Two channels share an id.                                                                                                                                  | Make ids unique.                                                                                                                                                                                                     |
| `pulse-notify: channel "<id>": checks must be an array of strings`                                                                                                                                             | `checks` has the wrong type.                                                                                                                               | Use `["check-id"]` or remove the key.                                                                                                                                                                                |
| `pulse-notify: channel "<id>": webhook needs a valid http(s) url`                                                                                                                                              | `url` is missing or not http(s).                                                                                                                           | Set a full `http://` or `https://` URL.                                                                                                                                                                              |
| `pulse-notify: channel "<id>": file channel needs a path`                                                                                                                                                      | `path` is missing or empty.                                                                                                                                | Set `path`.                                                                                                                                                                                                          |
| `pulse-notify: channel "<id>": unknown type "<type>"`                                                                                                                                                          | `type` is not `webhook`, `file`, `slack`, `teams` or `email`.                                                                                              | Use one of them.                                                                                                                                                                                                     |
| `pulse-notify: channel "<id>": urlEnv must hold an https url` (or `urlFile`)                                                                                                                                   | A Slack or Teams URL uses `http:`. Only `127.0.0.1` and `localhost` may.                                                                                   | Use the `https:` URL of the incoming webhook.                                                                                                                                                                        |
| `pulse-notify: channel "<id>": urlEnv: <NAME> is missing or empty` (also `urlFile`, `secretEnv`, `secretFile`, `passwordEnv`, `passwordFile`)                                                                  | The variable is unset or empty, or the file is empty.                                                                                                      | Set the variable or fill the file. The message never shows the value.                                                                                                                                                |
| `pulse-notify: channel "<id>": urlFile: cannot read file <path>`                                                                                                                                               | The secret file is missing or not readable (in Docker: not mounted).                                                                                       | Fix the path or the mount.                                                                                                                                                                                           |
| `pulse-notify: channel "<id>": set only one of urlEnv and urlFile`                                                                                                                                             | Both keys of a pair are set.                                                                                                                               | Keep one.                                                                                                                                                                                                            |
| `pulse-notify: channel "<id>": remindEverySeconds must be an integer of at least 60`                                                                                                                           | The interval is too short or not an integer.                                                                                                               | Use 60 or more.                                                                                                                                                                                                      |
| `pulse-notify: channel "<id>": smtp login is refused with tls "none" on a remote host`                                                                                                                         | A login would send the password in clear text.                                                                                                             | Use `starttls` or `tls`.                                                                                                                                                                                             |
| `pulse-notify: channel "<id>": to must be a single-line address` (also `from`, `subjectPrefix`)                                                                                                                | The value holds a line break.                                                                                                                              | Remove it.                                                                                                                                                                                                           |
| `pulse-notify: <NAME> must be a non-negative integer`                                                                                                                                                          | A numeric variable is not an integer ≥ 0.                                                                                                                  | Fix the value, for example `5000`.                                                                                                                                                                                   |
| `pulse-notify: PULSE_NOTIFY_POLL_MS: must be an integer of at least 1`                                                                                                                                         | The value is 0.                                                                                                                                            | Use 1 or more.                                                                                                                                                                                                       |
| `pulse-notify: PULSE_NOTIFY_TIMEOUT_MS: must be an integer of at least 1`                                                                                                                                      | The value is 0.                                                                                                                                            | Use 1 or more.                                                                                                                                                                                                       |
| `pulse-notify: cannot use state file <path>: <reason>` (exit code 2)                                                                                                                                           | The state file is JSON but not a version 1 or 2 ledger (a newer version is refused).                                                                       | Check `PULSE_NOTIFY_STATE` points to the right file. Move it away to start with a new ledger (all channels are seeded again).                                                                                        |
| `pulse-notify: state file <path> is in use by <host> pid <n> (heartbeat <s>s ago; remove <path>.lock if no pulse-notify runs)` (exit code 2)                                                                   | Another live process holds the state lock, or a crash left a lock that is not stale yet.                                                                   | Stop the other process. After a crash on another host, wait one lease (`PULSE_NOTIFY_LOCK_LEASE_SECONDS`) or remove the `.lock` file if you are sure nothing runs. See [operation.md](operation.md#state-file-lock). |
| `pulse-notify: state file lock <path> cannot be read (remove it if no pulse-notify runs)` (exit code 2)                                                                                                        | The lock file is corrupt. pulse-notify never takes over a lock it cannot read.                                                                             | Check that no process runs, then remove the `.lock` file.                                                                                                                                                            |
| `pulse-notify: another pulse-notify is taking over the state lock <path> (remove <path>.takeover if no pulse-notify runs)` (exit code 2)                                                                       | Another process is taking over a stale lock, or a crashed takeover left a corrupt `.lock.takeover` marker. A readable old marker clears itself after 10 s. | Wait and start again; if nothing runs, remove the `.lock.takeover` file.                                                                                                                                             |
| `pulse-notify: cannot use state file <path>: <reason>` (exit code 2)                                                                                                                                           | The state directory cannot be created or the lock cannot be written (permissions, read-only disk, a parent that is a file).                                | Fix the path or permissions of `PULSE_NOTIFY_STATE`.                                                                                                                                                                 |
| `pulse-notify: PULSE_NOTIFY_LOCK_LEASE_SECONDS: must be an integer of at least 30` (also `PULSE_NOTIFY_HEALTH_MAX_FAILED_POLLS`, `PULSE_NOTIFY_STATE_RETENTION_DAYS`, `PULSE_NOTIFY_API_MAX_BYTES` at least 1) | The value is too small.                                                                                                                                    | Use a larger value.                                                                                                                                                                                                  |
| `pulse-notify: PULSE_API_URL: must be a valid http(s) url`                                                                                                                                                     | The URL does not parse or is not `http:`/`https:`. The message never repeats it, because it can hold credentials.                                          | Fix the URL.                                                                                                                                                                                                         |
| `pulse-notify: PULSE_NOTIFY_SMTP_CLIENT_NAME: must be a host name or an address literal` (also `channel "<id>": smtp.clientName must be ...`)                                                                  | The EHLO name has spaces, line breaks or invalid characters.                                                                                               | Use a host name such as `pulse.example.com` or `[192.0.2.1]`.                                                                                                                                                        |
| `pulse-notify: cannot use state file <path>: <JSON error>` (exit code 2)                                                                                                                                       | The state file is not valid JSON, for example after a manual edit or a disk problem.                                                                       | Restore a copy, or move the file away.                                                                                                                                                                               |

Other startup lines: `pulse-notify: <file>: unknown key "<key>" in <place>` (a misspelled or unsupported key in the config file; fix or remove it), `pulse-notify: PULSE_LOG_LEVEL: must be one of debug, info, warn, error`, `pulse-notify: PULSE_HEALTH_PORT: must be an integer from 0 to 65535`, `pulse-notify: cannot listen on <host>:<port> (PULSE_HEALTH_HOST/PULSE_HEALTH_PORT): <reason>` (the health port is taken or not allowed; the exit code is 2 and no polling starts).

## While running

| Symptom or message                                                                         | Cause                                                                                                                                   | Action                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api poll failed` with `fetch failed` (see `code` and `cause`)                             | pulse-api is not reachable at `PULSE_API_URL`.                                                                                          | Check the URL, the network and that the API runs. In Docker, `localhost` is the container.                                                                                        |
| `api poll failed` with `timeout after <ms>ms`                                              | The API did not answer within `PULSE_NOTIFY_TIMEOUT_MS`.                                                                                | Check the API; raise the timeout.                                                                                                                                                 |
| `api poll failed` with `GET incidents returned <status>` or `GET checks returned <status>` | The API answered with an error.                                                                                                         | Check the API logs.                                                                                                                                                               |
| `api poll failed` with `GET <path> did not return an array`                                | `PULSE_API_URL` points at something that is not pulse-api.                                                                              | Fix the URL.                                                                                                                                                                      |
| `delivery attempt failed` with `webhook responded with status <code>`                      | The receiver rejected the call, or answered with a redirect (not followed).                                                             | Fix the receiver or the URL.                                                                                                                                                      |
| `webhook sends over http to a non-local host` (warn, once at start, with the channel id)   | A webhook `url` uses `http:`. Payload and signature travel in clear text.                                                               | Use `https:`. The channel still works.                                                                                                                                            |
| `delivery attempt failed` with `slack responded with status 429` (or `teams`)              | The service rate limits the webhook. `Retry-After` is not used.                                                                         | The attempt is retried with the normal back-off. Lower the number of messages, for example raise `remindEverySeconds`.                                                            |
| `delivery attempt failed` with `<channel> request failed`                                  | The webhook host cannot be reached. The URL is left out on purpose; see `code`.                                                         | Check DNS, network and the URL in the secret.                                                                                                                                     |
| `delivery attempt failed` with `SMTP <step> failed: <code> <text>`                         | The mail server refused a command with a 4xx code. A 5xx code is permanent and not retried (see the next rows).                         | Read the code and text, for example `535` is a wrong login, `550` a rejected recipient.                                                                                           |
| `SMTP send timed out after <ms>ms`, `SMTP failed: ECONNECTION`, `SMTP failed: ESOCKET`     | The server is silent or hangs up.                                                                                                       | Check host, port and `smtp.tls`: port 465 needs `tls`, port 587 needs `starttls`.                                                                                                 |
| `SMTP server does not offer STARTTLS`, or a certificate error                              | `starttls` was chosen but the server has no TLS, or its certificate is not trusted (verification cannot be turned off).                 | Fix the server, or use a certificate from a trusted CA.                                                                                                                           |
| `stale reminder dropped`                                                                   | A reminder was queued when its incident resolved.                                                                                       | Expected. The ledger marks the key `dropped`.                                                                                                                                     |
| `notification delivery failed`                                                             | All attempts failed (12 by default, about 6 minutes). The event is final.                                                               | Fix the cause, read `code` and `cause`. The missed notification is not resent; check the incident in pulse-api, or set `PULSE_NOTIFY_RETRY_ATTEMPTS=0`.                           |
| `notification delivery failed` with `permanent: true`                                      | The receiver answered with a 4xx status (not 408 or 429), or the mail server with a 5xx code. A retry would not help.                   | Fix the URL, the credential or the address. Then run `node src/index.ts failed resend <key>` with the service stopped. See [operation.md](operation.md#failed-events-and-resend). |
| `/healthz` is 503 with `polls failing (<n> in a row)`                                      | The last polls failed: pulse-api is down or unreachable, sends bad data, or a body over `PULSE_NOTIFY_API_MAX_BYTES`.                   | Read the `api poll failed` lines. One good poll makes `/healthz` 200 again.                                                                                                       |
| `state lock lost, stopping` (exit code 2)                                                  | Another process took over the lock file, for example after the heartbeat stalled longer than the lease.                                 | Make sure only one process uses the state file; restart.                                                                                                                          |
| `resending pending notifications` at start                                                 | The process stopped while events were unfinished.                                                                                       | Expected. They are sent again; deduplicate by `key`.                                                                                                                              |
| `pending notification cannot be rebuilt: incident not found`                               | A `pending` key from an older version has no stored notification and the API no longer returns the incident.                            | Check the receiver by `key`. The key stays `pending`.                                                                                                                             |
| `incident skipped: malformed data`                                                         | pulse-api returned an incident with a bad field, for example an `openedAt` or `resolvedAt` outside the range of a `Date` (±8.64e15 ms). | Check the API data. The incident is checked again on every poll.                                                                                                                  |
| `ledger claim failed`, `ledger settle failed` or `ledger seed failed`                      | The state file cannot be written (disk full, permissions).                                                                              | Fix the disk or the path. A settle failure causes a duplicate send at the next start.                                                                                             |
| No notification for an incident that existed at first start                                | The channel was seeded.                                                                                                                 | Expected. See [channels.md](channels.md#delivery-and-retries).                                                                                                                    |
| No notification at all                                                                     | pulse-api opens no incident, or the channel's `checks` filter does not list the check id.                                               | Check `GET /incidents` and the `checks` keys. See [quorum and incidents](https://github.com/lorenzh/pulse-api/blob/main/docs/concepts.md#quorum-and-incidents).                   |
| A webhook receiver gets the same event twice                                               | Possible: delivery is at least once, and a retry can deliver an event twice.                                                            | Drop duplicates on the receiver by the `idempotency-key` header (`<incident id>:<event>`).                                                                                        |
