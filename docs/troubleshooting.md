# Troubleshooting

Messages are quoted from the code. `<x>` marks a value that varies.

## Startup

| Message                                                                                     | Cause                                                                                | Action                                                                                                                        |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `configuration error: PULSE_NOTIFY_CONFIG is required`                                      | The variable is unset or empty.                                                      | Set it to the path of the channel config file.                                                                                |
| `configuration error: cannot read config file <path>: <reason>`                             | The file is missing or not readable. In Docker, the file is not mounted.             | Fix the path or the mount.                                                                                                    |
| `configuration error: config file <path> is not valid JSON: <reason>`                       | The file has a JSON syntax error.                                                    | Fix the JSON.                                                                                                                 |
| `configuration error: config must be an object`                                             | The top level is not an object.                                                      | Use `{ "channels": [...] }`.                                                                                                  |
| `configuration error: config.channels must be a non-empty array`                            | `channels` is missing, not an array or empty.                                        | Add at least one channel.                                                                                                     |
| `configuration error: channels[<n>] must be an object`                                      | An entry is not an object.                                                           | Fix entry `<n>` (counting from 0).                                                                                            |
| `configuration error: channels[<n>].id must be a non-empty string`                          | An id is missing or empty.                                                           | Give every channel an `id`.                                                                                                   |
| `configuration error: duplicate channel id "<id>"`                                          | Two channels share an id.                                                            | Make ids unique.                                                                                                              |
| `configuration error: channel "<id>": checks must be an array of strings`                   | `checks` has the wrong type.                                                         | Use `["check-id"]` or remove the key.                                                                                         |
| `configuration error: channel "<id>": webhook needs a valid http(s) url`                    | `url` is missing or not http(s).                                                     | Set a full `http://` or `https://` URL.                                                                                       |
| `configuration error: channel "<id>": file channel needs a path`                            | `path` is missing or empty.                                                          | Set `path`.                                                                                                                   |
| `configuration error: channel "<id>": unknown type "<type>"`                                | `type` is not `webhook` or `file`.                                                   | Use one of the two.                                                                                                           |
| `configuration error: <NAME> must be a non-negative integer`                                | A numeric variable is not an integer ≥ 0.                                            | Fix the value, for example `5000`.                                                                                            |
| `configuration error: PULSE_NOTIFY_POLL_MS must be at least 1`                              | The value is 0.                                                                      | Use 1 or more.                                                                                                                |
| `configuration error: PULSE_NOTIFY_TIMEOUT_MS must be at least 1`                           | The value is 0.                                                                      | Use 1 or more.                                                                                                                |
| `ledger <path> has an unsupported format` (uncaught error, exit code 1, with a stack trace) | The state file is JSON but not a version 1 ledger.                                   | Check `PULSE_NOTIFY_STATE` points to the right file. Move it away to start with a new ledger (all channels are seeded again). |
| A JSON `SyntaxError` at start (uncaught, exit code 1)                                       | The state file is not valid JSON, for example after a manual edit or a disk problem. | Restore a copy, or move the file away.                                                                                        |

## While running

| Symptom or message                                                                         | Cause                                                                                     | Action                                                                                                                                                          |
| ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api poll failed` with `fetch failed`                                                      | pulse-api is not reachable at `PULSE_API_URL`.                                            | Check the URL, the network and that the API runs. In Docker, `localhost` is the container.                                                                      |
| `api poll failed` with `timeout after <ms>ms`                                              | The API did not answer within `PULSE_NOTIFY_TIMEOUT_MS`.                                  | Check the API; raise the timeout.                                                                                                                               |
| `api poll failed` with `GET incidents returned <status>` or `GET checks returned <status>` | The API answered with an error.                                                           | Check the API logs.                                                                                                                                             |
| `api poll failed` with `GET <path> did not return an array`                                | `PULSE_API_URL` points at something that is not pulse-api.                                | Fix the URL.                                                                                                                                                    |
| `delivery attempt failed` with `webhook responded with status <code>`                      | The receiver rejected the call, or answered with a redirect (not followed).               | Fix the receiver or the URL.                                                                                                                                    |
| `notification delivery failed`                                                             | All 4 attempts failed. The event is not retried.                                          | Fix the cause. The missed notification is not resent; check the incident in pulse-api.                                                                          |
| `notification possibly lost: claimed but never settled`                                    | The process stopped between claim and send.                                               | Check the receiver by `key`. The event is not resent.                                                                                                           |
| No notification for an incident that existed at first start                                | The channel was seeded.                                                                   | Expected. See [channels.md](channels.md#delivery-and-retries).                                                                                                  |
| No notification at all                                                                     | pulse-api opens no incident, or the channel's `checks` filter does not list the check id. | Check `GET /incidents` and the `checks` keys. See [quorum and incidents](https://github.com/lorenzh/pulse-api/blob/main/docs/concepts.md#quorum-and-incidents). |
| A webhook receiver gets the same event twice                                               | Possible: delivery is at least once, and a retry can deliver an event twice.              | Drop duplicates on the receiver by the `idempotency-key` header (`<incident id>:<event>`).                                                                      |
